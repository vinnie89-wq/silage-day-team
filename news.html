Set up automatic translation

Without this, "Translate into Welsh" opens Google Translate in a new tab for you to copy the Welsh back. With a Google Cloud Translation key it fills the boxes in for you.

  1. In the Google Cloud console for the silage-day project (the same one Firebase uses), turn on the Cloud Translation API. It needs the project's billing turned on (the Blaze plan); the first 500,000 characters a month are free.
  2. APIs & Services → Credentials → Create credentials → API key. Restrict it to Websites: vinnie89-wq.github.io/*, and to the Cloud Translation API only.
  3. Paste the key here and save. It's kept in the organisers-only part of the database, never in the app's code.
